# Install Renwei Writing for Zerone

## Prerequisites

- [Zerone](https://www.zerone.run/) installed
- Git installed

## Installation Steps

### 1. Clone the renwei-writing repository

```bash
git clone https://github.com/orange2ai/renwei-writing.git ~/.agents/skills/renwei-writing
```

### 2. Verify Installation

Restart Zerone, then try asking:
- "Do you know Renwei Writing?"
- "Help me polish this paragraph"

If successful, Zerone will automatically recognize and invoke the Renwei Writing skill.

## Updating

```bash
cd ~/.agents/skills/renwei-writing
git pull
```

## Uninstallation

```bash
rm -rf ~/.agents/skills/renwei-writing
```
