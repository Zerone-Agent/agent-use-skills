# Aaron 营销技能库

**Aaron 营销技能库**是面向 AI Agent 的 69 技能营销操作员,覆盖四个学科 —— SEO/GEO、红人营销(IMPACT)、付费广告(ROAS)、邮件营销(SEND)—— 共享同一套运行契约,内置五个基准驱动的审计门与零依赖免密钥数据连接器。

## 标签

📈 营销与增长 | ✅ 已验证

## 核心理念

- **一套契约,69 个技能**:每个技能暴露相同的段落结构(触发 → 快速开始 → 技能契约 → 交棒摘要 → 下一最佳技能),整个库像一套操作系统 —— 每个技能都知道自己的输入、输出和该交棒给谁。
- **有门的质量,不靠感觉**:五套基准(CORE-EEAT、CITE、C³、ROAS、SEND)驱动五个审计门,产出可机器校验的 SHIP / FIX / BLOCK 判定与否决规则。
- **默认免密钥**:每个技能都能仅凭粘贴的数据在 Tier-1 运行;可选的 Python 标准库连接器拉取免费/自有数据(Search Console、GA4、维基百科关注度、DNS 邮件认证记录、YouTube 指标等),无需付费工具。
- **真相住在注册表里**:品牌实体、创作者档案、offer/声明实证、同意记录都在协议层专职注册表中,审计门对照注册表评判。

## 主要功能与工作流

1. **SEO/GEO(16 个)**—— 关键词/SERP/缺口研究、内容创作、GEO 引用就绪、Schema、程序化/寄生/本地打法,再经 CORE-EEAT 与 CITE 审计,加排名与站外监控。
2. **红人 · IMPACT(16 个)**—— 受众/细分社群画像、红人发现与适配评分、活动规划与简报、建联、C³ ART 合规门、内容放大与 ROI 度量。
3. **付费广告 · ROAS(16 个)**—— 活动架构、受众分层、创意与实验、RQS 投放门与转化信号 QA,再到归因对账、预算节奏与疲劳管理。
4. **邮件 · SEND(16 个)**—— 送达/认证预检、列表增长与清洁、创意与渲染、生命周期流程、Newsletter 变现、EQS 发送前门、收件箱落位监控。
5. **协议层(5 个)**—— 实体/创作者/声明/同意四个真相注册表 + HOT/WARM/COLD 跨会话记忆。
